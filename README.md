# Daffodil

Daffodil is maintained in separate version projects:

- `v1.20.1` is the preserved Forge project. It is retained as the historical version.
- `v26.3` is the new NeoForge port, using Java 25.

Open the folder for the target version in IntelliJ IDEA and run its `gradlew` wrapper from that folder. The root `settings.gradle` includes both folders for IDE discovery.
